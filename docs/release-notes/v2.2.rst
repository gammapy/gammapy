2.2 (27th November, 2026)
=========================

- Released: 27th November, 2026
- New contributors: 7 (Marked with * in the list)
- Total contributors: 30
- Total merged PRs: 200


Summary
-------

Gammapy v2.2 is a new feature release with a number of performance improvements,
new features and bug fixes. The main themes include new tools for Bayesian inference,
a broad overhaul of the dark matter module, and ASDF serialization of the core data
structures.

Python 3.14 and 3.15 are now supported, and issues encountered with `~regions` in the
previous versions are now resolved. Three new notebooks have been added and the CTAO
notebook significantly updated.

A security vulnerability was found (CVE-2026-134694). When reading a WCS map from a
FITS file (e.g. with `gammapy.maps.Map.read`), Gammapy (<=2.1) evaluates the content
of the ``WCSSHAPE`` GADF header keyword as Python code. A maliciously crafted FITS file
could therefore execute arbitrary code as user on your computer when opened.
**All Gammapy versions up to 2.1 are affected.** This has been adjusted in this version.
We thank Dilanka Kaushal Hewage (@r3vpwnx) for reporting the issue.

Dark matter module
~~~~~~~~~~~~~~~~~~

The dark matter module has been substantially refactored and extended in this release.
The spectral model classes have been unified into a single class handling both annihilation
and decay, with improved parameter validation and an overall cleaner code structure.
``CosmiXs`` is now the default source for dark matter spectra, replacing ``PPPC4DMID``;
note that this changes the results of analyses that relied on the previous default.
Users can also provide their own custom spectra from a file.

The computation of astrophysical factors has been improved, with corrections for extragalactic sources,
the line-of-sight geometry and the treatment of the central pixel.
Notably, uncertainties on the astrophysical factor can now be included as a
nuisance parameter profiled in the likelihood fit,
so that limits on the annihilation cross-section or decay lifetime account for the
uncertainty on the target's dark matter distribution, yielding more realistic
and typically more conservative constraints. The documentation and tutorials have been updated accordingly,
with new and improved tutorials covering both a basic introduction and a complete analysis.

ASDF serialization
~~~~~~~~~~~~~~~~~~~

Maps, geometries (WCS, HEALPix, region), map axes,
GTIs, IRF maps, Datasets and Models can now be written to and read from ASDF.
This is the groundwork for storing a complete analysis state in a single, self-describing file,
and is a part of an overhaul of the I/O code in Gammapy. An associated entry in the
:ref:`HowTo <doc_howto>` is added as an explanation for ASDF serialisation.


Estimators and flux upper limits
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Significant additions have been made to our estimator package.
Previously, hidden failures sometimes used to occur at low statistics, causing
very low upper limits. This has now been corrected. If a failure is detected during
the fit for upper limit computation, the method internally switches to upper limit
computation using likelihood profiles. The upper limit tutorial has been updated with
more information.

A preliminary implementation of a new `~gammapy.estimators.RegularizedFluxPointsEstimator`
is introduced for flux point computation in true-energy space
with a given regularisation, and will be documented in future releases.


Other
~~~~~

The 4FGL catalog is updated, with support for the FL16Y list. A new
`~gammapy.makers.OnOffBackgroundMaker` with an associated tutorial is provided
for background estimation with paired off runs. The
`nautilus <https://nautilus-sampler.readthedocs.io/en/latest/>`_
is now available as a `~gammapy.modeling.Sampler` backend, which is better suited for
higher dimensionality problems, and `~gammapy.modeling.models.LogNormalPrior` and
`~gammapy.modeling.models.SamplesKDEPrior` are introduced. A new tutorial is added
explaining the details of Bayesian model selection.

API changes
-----------

- The constructor of `~gammapy.data.ObservationTable` now takes an argument ``table`` instead of ``data``. [`#6620 <https://github.com/gammapy/gammapy/issues/6620>`_]
- Deprecated `~gammapy.makers.utils.make_map_exposure_true_energy`, use the ``make_exposure`` method on `~gammapy.makers.MapDatasetMaker` instead. [`#6882 <https://github.com/gammapy/gammapy/issues/6882>`_]
- Deprecate `gammapy.makers.utils.make_psf_map`. [`#6893 <https://github.com/gammapy/gammapy/issues/6893>`_]
- The options of `~gammapy.modeling.Sampler` are now given in a single ``options`` dictionary, using the backend's own option names. [`#6898 <https://github.com/gammapy/gammapy/issues/6898>`_]
- Deprecate `gammapy.makers.utils.make_edisp_map` and `gammapy.makers.utils.make_edisp_kernel_map`. [`#6906 <https://github.com/gammapy/gammapy/issues/6906>`_]
- Deprecate `gammapy.makers.utils.make_map_background_irf`. [`#6946 <https://github.com/gammapy/gammapy/issues/6946>`_]
