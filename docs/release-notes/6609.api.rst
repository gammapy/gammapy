The options of `~gammapy.modeling.Sampler` are now given in a single ``options`` dictionary, using the backend's own
option names. When the sampler runs, Gammapy passes each of them to the backend sampler constructor or to its ``run``
method, based on the signatures of the installed backend library. The ``sampler_opts`` and ``run_opts`` arguments
and attributes are deprecated, use ``options`` instead. For the "ultranest" backend, ``live_points`` is deprecated
and replaced by ``min_num_live_points``. The ``step_sampler`` and ``nsteps`` options of the "ultranest" backend,
which added an UltraNest slice step sampler, are removed.
