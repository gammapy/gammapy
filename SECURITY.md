# Security Policy

If you believe you have found a security vulnerability, please report it as described below.

## Supported Versions

The table below indicates which versions of `gammapy` are
currently being supported with security updates.

| Version      | Supported          |
| ------------ | ------------------ |
| 2.2.x (main) | :white_check_mark: |
| 2.0.x (LTS)  | :white_check_mark: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Please report security vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/gammapy/gammapy/security/advisories/new).
If that does not work for you, contact the
[gammapy lead-devs](https://gammapy.org/team.html#ld).

We will respond as soon as we are able. If a vulnerability is accepted, we will
work on a fix. The timing depends on the
available resources and the severity of the vulnerability.
